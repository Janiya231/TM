# RecordFlow — Recording Management System

A local/offline student recording manager built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a modern browser.

## Storage
All data is stored in browser LocalStorage under `recordFlow_v1`.

## Features
- Dashboard and statistics
- Subjects
- Recording CRUD
- Watch-progress tracking
- Continue watching
- Completion tracking
- Spaced-repetition reviews
- Calendar
- Analytics
- Search and filters
- JSON import/export
- Dark/light mode
- Responsive desktop/mobile UI

No backend or login is required.
